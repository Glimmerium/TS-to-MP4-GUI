# 参与改进

欢迎提交针对 TS → MP4 使用体验的修复与小改进。

1. 使用包含 Tcl/Tk 的 Windows Python 环境，按 README 运行源码。
2. 修改应保留中文界面、原文件保护和取消流程；转换相关改动请说明对快速无损和重新编码两种模式的影响。
3. 提交时说明改动原因、验证过的环境，以及尚未验证的部分。

反馈显示问题时请提供屏幕分辨率、Windows 缩放比例和截图。反馈转换问题时请提供模式、FFmpeg 版本及去除个人信息后的日志。优先使用自己生成的短测试视频复现，无需提供课程录像。

不要提交视频、构建环境、FFmpeg 二进制文件、登录信息或本机绝对路径。
